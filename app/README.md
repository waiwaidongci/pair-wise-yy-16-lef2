# 选片台 · 离线校样与成套留痕

基于 `mock-data/` 摄影作品包的离线选片工具：按片序展示校样墙、三选一标记、成套锁定与版本留痕、跨系列比较。全部数据保存在本机 localStorage，无任何网络依赖。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
npm run test     # 状态规则层 / 记录存储层单元测试（vitest）
node e2e-verify.mjs   # 浏览器实测（需先 npm run build，依赖 playwright）
```

## 分层结构

| 层 | 位置 | 职责 |
|---|---|---|
| 状态规则 | `src/domain/` | 纯函数：标记归并（重复提交沿用首次结果）、锁定前置条件、失效判定、跨系列统计。不碰 React 与 IO |
| 记录存储 | `src/storage/` | localStorage 读写、schema 校验与损坏回退；存储介质可注入，便于测试 |
| 界面 | `src/ui/`、`src/App.tsx` | 校样墙 / 逐张复核 / 成套留痕 / 跨系列比较四个视图；`ui/store.tsx` 负责把规则层与存储层接到 React |

内容数据（`src/data/photos.ts`）直接引用仓库根部的 `mock-data/photos.json`，不复制、不增删；照片与字体文件拷贝在 `public/` 下离线提供。

## 核心规则

- 每张照片同一时刻只有一份标记（入选 / 待复核 / 排除）；重复提交同一标记沿用首次结果（记录与时间戳不变）。
- 锁定成套的前置条件：系列内全部照片已标记、无待复核、且当前没有仍有效的成套。
- 锁定后任何标记改动使该版**立即失效**（失效不可逆，即使改回快照值）；旧版永久保留在「成套留痕」中可查，并能对照当前标记看差异。
- 「跨系列比较」只读取当前有效标记，历史锁定快照不参与统计。
- 筛选条件、片序模式、复核位置与锁定记录均持久化，刷新后保持一致；移动端为单列布局，逐张复核支持大按钮与键盘快捷键（←/→ 切换，1/2/3 标记）。
